# Skill — Evidence Check

## Purpose
Review a result before it reaches the user and flag unsupported facts, numbers, links, or claims.

## Use When
A result contains factual assertions or external references.

## Inputs
- draft result
- source material, if any

## Output
- PASS, PASS WITH WARNINGS, or FAIL
- unsupported claims
- missing evidence
- corrected or qualified wording

## Rules
- Never invent a source.
- Never convert uncertainty into certainty.
- Distinguish inference from evidence.
- If no evidence is available, say so.
