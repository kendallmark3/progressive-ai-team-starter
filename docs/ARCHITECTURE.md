# Architecture

## Human Zone
The human declares outcomes, boundaries, approvals, success criteria, and observed feedback.

## AI Zone
Claude chooses implementation details, performs reasoning, and proposes the minimum next change.

## Deterministic Zone
Hooks enforce non-negotiable rules such as approval and validation.

## Evolution
V1: intent + one lead + quality gate + evidence.

V2+: add skills, specialized agents, integrations, or automation only when run evidence proves the need.
