# V1 Workflow

1. Receive one user request.
2. Identify the intended outcome.
3. Perform the work with the lead agent.
4. Run the quality/evidence check.
5. If consequential action is needed, stop at the approval gate.
6. Return the result.
7. Ask: KEEP, CHANGE, or DROP?
8. Record evidence and feedback.
9. Do not add anything else unless the evidence justifies it.
